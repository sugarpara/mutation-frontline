# 异变前线（Mutation Frontline）

《异变前线》是一款原创的单机网页版 3D 第一人称射击游戏原型。项目采用 Vite、TypeScript 和 Three.js 开发，所有地图、角色、武器名称、低多边形造型、界面与程序化音效均为原创设计，不使用第三方付费素材。

## 启动方法

需要 Node.js 20.19+ 或 22.12+。

```bash
npm install
npm run dev
```

浏览器打开终端显示的本地地址。生产构建：

```bash
npm run build
npm run preview
```

## 操作按键

| 按键 | 操作 |
| --- | --- |
| `W A S D` | 移动 |
| 鼠标 | 控制视角 |
| 鼠标左键 | 射击 / 近战攻击 |
| `R` | 换弹 |
| `Space` | 跳跃 |
| `Shift` | 冲刺 |
| `1 / 2 / 3` | 主武器 / 手枪 / 近战武器 |
| `E` | 爆破模式中按住安装或拆除爆破核心 |
| `Esc` | 释放鼠标并暂停 |

开发环境额外提供：`F2` 强制下一局玩家为人类、`F3` 强制下一局玩家为初始母体、`F4` 立即结束准备倒计时。这些按键不会出现在生产构建的正式 HUD 中。

游戏使用 Pointer Lock。开始行动或从暂停菜单继续时，浏览器会锁定鼠标。

## 已实现功能

- 完整单机生化感染回合：玩家与 7 名 AI、10 秒准备、从全部 8 名角色中随机选择 3 名初始感染体（1 名母体与 2 名普通感染体）、180 秒胜负计时。
- 完整单机战术爆破比赛：4v4、先得 4 分获胜，前三回合玩家担任进攻方，第四回合起换边防守；每回合包含 5 秒冻结准备、150 秒行动时间和独立结算。爆破模式使用独立地图池，不会加载生化地图。
- A/B 双目标区、爆破核心携带/掉落/拾取、玩家按住 `E` 安装或拆除、AI 自动安装与拆除，以及击杀、超时、拆除和引爆胜负判定。
- 安装与拆除为独占交互：期间角色无法移动或射击，松开按键、离开范围、受击或阵亡会中断进度；不同角色不能无成本接续拆除进度。
- 人类被感染体近战击败后进入约 1 秒感染僵直，再切换阵营、模型与 AI；玩家被感染后继续使用双爪作战。
- 普通感染体 300 生命、母体 600 生命；感染体近战伤害 35，带前摇、命中时刻和冷却；被枪械击退后 3 秒在安全感染点重组。
- 人类胜利、感染体胜利、重新开始和返回主菜单流程。
- WASD 移动、鼠标视角、冲刺、跳跃、碰撞、地图边界和不同高度地形。
- 四种原创角色外观：重甲突击队员陆沉、轻装侦察兵沈拓、浅色医疗兵林澈、蓝色目镜战术专家季遥。
- 人类角色采用分层胸甲、头盔、护膝、战术手套和关节化四肢；普通感染体与母体拥有独立甲壳、头冠、利爪、背刺、发光核心和体型轮廓。
- 炎龙·原型突击步枪、P9 微光手枪、V3 高频刃和感染体双爪。生化模式仅剩一名人类时会晋升为最后英雄，并切换 MX-100 曜日重机枪；额外特殊感染体仍保留为后续设计方向。
- “炎龙·原型”使用程序化低多边形完整结构、暗色分层机匣、余烬能量腔、克制黄铜饰条、原创脊片轮廓、独立 viewmodel、双手持枪、移动与冲刺摆动、靠墙收枪、枪机后坐、枪焰烟雾、弹壳物理和分阶段换弹动画。
- 弹匣/备用弹药、射击间隔、换弹、后坐力、连续射击准星扩散、枪口闪光、曳光、命中反馈和头部伤害倍率。
- 程序化 Web Audio 射击、命中、换弹、感染、倒计时和结算提示音。
- AI 状态机：防守、分散跟随、搜索、射击、躲避、换弹、低血后撤、追击、带前摇近战、局部分离、重新寻路和卡住脱困。
- 五张原创程序化地图。生化地图池包含沙脊炼化基地、夜港货运站和 Q-17 地下隔离区；爆破地图池包含 C-9 高塔中继站和赤砧装配厂。两种模式不共用地图，爆破地图还拥有显式 A/B 目标区与独立攻守出生区。
- 生化默认战场为 Q-17 地下隔离区，使用冷色实验室照明、红色警戒光和培养舱等原创场景结构；爆破默认战场为 C-9 高塔中继站。全部场景保持原创，不复制参考游戏资产。
- 可交互武器仓库：主武器/副武器/近战分类、武器展示、属性条和初始武器装备选择。
- HUD 显示实时相对位置雷达、阵营人数、准备倒计时、回合时间、感染威胁、击杀提示、武器/利爪状态和方向受伤提示；结算显示击杀、感染数和人类存活时间。窄屏会自动收起雷达，避免遮挡计分栏。

## 设计说明

当前版本优先保证玩法闭环和浏览器性能。导航采用按地图布置的导航节点、A* 路径计算、视线检测、圆形碰撞解析、角色分离和卡住后的侧向脱困。地图、枪械、角色和感染体均由 Three.js 基础几何体与程序化材质构建；音频使用浏览器实时合成，因此不需要外部付费素材。

## 后续开发计划

- 基于导航网格的更精细路径规划与队形协作。
- 将已记录的额外幽灵、母体变体与更多英雄变体作为独立后续阶段实现，不提前耦合到当前核心模式。
- 更多原创武器配件、角色动作、地图事件和环境交互。
- 局内计分板、难度选择、画质预设和按键自定义。
- 爆破模式的经济购买、装备保留、赛点演出与更细致的战术协作。
- 在独立服务端架构验证后再评估真人联机，不与当前单机逻辑耦合。
